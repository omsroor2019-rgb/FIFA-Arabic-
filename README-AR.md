# مصادر الأصول المجانية المقترحة — FIFA Arabic

> هذا الملف يسجل مصادر الأصول التي تمت مراجعة صفحات ترخيصها. قبل إدخال أي ملف إلى اللعبة، احفظ نسخة من صفحة الأصل وملف الترخيص المرفق به داخل `docs/licenses/`؛ لأن ترخيص كل عنصر داخل المنصة قد يختلف عن عنصر آخر.

## 1) اللاعبون والحركات

### الخيار العملي الأول للهاتف: شخصية بشرية Rigged + Mixamo
- **Diesel — شخصية بشرية Rigged بصيغة GLB/FBX**: https://theunseenvulga.itch.io/3d-charater-riggeddiesel
- الملفات المذكورة في صفحة الأصل: GLB بحجم 10MB وFBX بحجم 12MB، وعدد المثلثات نحو 18.5–19 ألف.
- الترخيص المعلن: CC0؛ استخدام شخصي وتجاري وتعديل دون نسب إلزامي. يمنع فقط إعادة بيع الملف الأصلي كما هو أو ادعاء إنشائه.
- ملاحظة: النموذج شخصية بشرية عامة، وليس لاعب كرة قدم جاهزاً. يلزم تعديل ملابسه إلى طقم كرة قدم في Blender ثم تجهيز الهيكل والحركات.

### الحركات
- **Adobe Mixamo**: https://www.mixamo.com/
- الأسئلة الشائعة الرسمية: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html
- Mixamo مجاني بحساب Adobe، وتسمح Adobe باستخدام الشخصيات والحركات في ألعاب الفيديو والمشاريع التجارية والشخصية دون رسوم ملكية وفق FAQ. يدعم الشخصيات البشرية ثنائية الأرجل.
- مقترح الحركات: Idle، Walk، Run، Sprint، Turn، Dribble، Pass، Shoot، Tackle، Jump، Fall، Celebrate، Goalkeeper Save.
- لا تستخدم صوت أو وجه أو اسم معلق أو لاعب مشهور دون إذن منفصل.

### لاعب كرة قدم جاهز بحركات مدمجة — خيار ثقيل
- **African Football Soccer Player Male — CGTrader**: https://www.cgtrader.com/free-3d-models/character/man/african-football-soccer-player-male
- الصفحة تصفه كنموذج لاعب كرة قدم Rigged وتذكر 15 حركة (ومنها الجري والوقوف والركلة والركلة الجزائية) وترخيص Royalty Free مع استخدام شخصي وتجاري.
- تحذير حجم: صفحة المنتج تعرض ملفات FBX مجموعها المعلن 875MB وملفات خامات JPG بحجم 732MB؛ هذا ضخم جداً للنسخة الأولى على الهاتف. لا ننصح بدمج الحزمة كاملة قبل تنزيل نسخة مخفّضة والتحقق من ملفاتها والترخيص المرفق.

### نموذج لاعب ساكن — ليس للاعب المتحرك
- **Soccer Player Standing — Innerscene**: https://www.innerscene.com/tools/library/3d-parts/soccer-player-standing-3d-person-team-sports-f55b1b4f
- GLB بحجم 17.5MB، CC0، لكن وصف الصفحة ينص صراحةً أنه Static Mesh بلا Armature أو Animation. يصلح لصورة/لقطة أو مجسم خلفية، وليس لاعباً قابلاً للتحريك قبل عمل Rigging.
- **Soccer Player Kicking — Innerscene**: https://www.innerscene.com/tools/library/3d-parts/soccer-player-kicking-3d-person-team-sports-bc15ef89
- GLB بحجم 17.5MB، CC0، لكنه أيضاً بلا Armature أو Animation؛ لا يُستخدم كحركة لعب فعلية.

## 2) الملعب والبيئة

- **Football Stadium — Innerscene**: https://www.innerscene.com/tools/library/3d-parts/football-stadium-f7b93967
- GLB بحجم 11MB، CC0، ملعب عام مع مدرجات من مستويين، سعة تقديرية تقارب 42 ألف مقعد، أرضية وعلامات ومرميين، دون شعارات أو إعلانات تجارية.
- الملعب أكبر من ملعب النسخة الحالية؛ عند الاستيراد يجب توحيد المقاس والمحاور والاصطدامات والكاميرا، ثم اختبار أداء Android.
- **Poly Haven**: https://polyhaven.com/ — خامات PBR وHDRI ونماذج 3D بترخيص CC0، للاستخدام التجاري وإعادة التوزيع ضمن المنتج.
- **Quaternius**: https://quaternius.com/ — شخصيات وبيئات وتحريكات. كل حزمة لها ترخيصها؛ إما CC0 أو QAL. يسمح QAL باستخدام الأصول داخل لعبة تجارية دون رسوم أو نسب، لكنه يمنع إعادة توزيع الأصول كحزمة أصول مستقلة.

## 3) الكرة والواجهة

- **Soccer Ball — dLeom**: https://dleom.itch.io/3d-soccer-ball
- نموذج كرة بصيغ OBJ/FBX/GLB/BLEND، الصفحة تعلن CC0.
- **Kenney**: https://kenney.nl/assets — أصول UI وأيقونات وأصوات. صفحة الدعم تؤكد أن أصول الألعاب المنشورة لديه CC0 للاستخدام التجاري، ولا تتطلب نسباً.
- **Kenney Sports Pack**: https://kenney.nl/assets/sports-pack — الحزمة المذكورة 2D وCC0؛ تصلح للرموز أو عناصر الواجهة، وليست نماذج لاعبين 3D.

## 4) الأصوات والمؤثرات

- **Kenney Impact Sounds**: https://kenney.nl/assets/impact-sounds — صفحة الحزمة تعلن CC0. يمكن اختيار أصوات اصطدام/لمسات للكرة وتكييفها.
- **Freesound**: https://freesound.org/ — استخدم فلتر CC0 فقط عند البحث عن `stadium crowd`, `whistle`, `football kick`, `goal cheer`. ترخيص الملفات يختلف من ملف لآخر؛ CC-BY يتطلب نسباً وCC-BY-NC لا يصلح للعبة تجارية.
- **Pixabay Sound Effects**: https://pixabay.com/sound-effects/ — الترخيص يسمح بالاستخدام المجاني والتعديل دون نسب عادةً، لكنه يمنع إعادة توزيع المحتوى كملف مستقل؛ افحص الحقوق الإضافية لكل ملف.

## 5) التعليق العربي

- **SILMA TTS**: https://huggingface.co/silma-ai/silma-tts — نموذج تحويل نص عربي/إنجليزي إلى كلام، الصفحة تعرض ترخيص Apache-2.0.
- الاستخدام المقترح: توليد مقاطع تعليق أصلية مسبقاً من نصوص اللعبة (بداية المباراة، تمريرة، تسديدة، تصدٍ، هدف، نهاية المباراة)، ثم تضمين ملفات WAV/OGG محلياً في اللعبة.
- لا تستنسخ صوت معلق رياضي معروف، ولا تستخدم صوته أو اسمه أو عباراته المميزة دون إذن. نستخدم صوتاً أصلياً مرخصاً.
- يلزم اختبار نطق أسماء اللاعبين واللهجة العربية قبل اعتماد المقاطع. النموذج ليس ملف تعليق جاهزاً؛ هو أداة لتوليد الصوت ويحتاج خطوة إنتاج منفصلة.

## 6) اللعب عبر الإنترنت

- **Nakama Open Source**: https://heroiclabs.com/nakama/ — خادم ألعاب مفتوح المصدر، وترخيص الخادم والعملاء Apache-2.0 بحسب صفحة الترخيص الرسمية. يدعم الحسابات والغرف والمباريات الفورية والميزات الاجتماعية.
- **Godot High-Level Multiplayer**: https://docs.godotengine.org/en/4.7/tutorials/networking/high_level_multiplayer.html — Godot يدعم ENet وWebRTC وWebSocket.
- ملاحظة مهمة: الكود مفتوح المصدر لا يعني أن الاستضافة الدائمة مجانية. تحتاج مباراة الإنترنت إلى خادم متاح باستمرار واتصال يمكن للاعبين الوصول إليه؛ GitHub Actions لبناء APK وليس لاستضافة مباريات اللاعبين على مدار الساعة.
