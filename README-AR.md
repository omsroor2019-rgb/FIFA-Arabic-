# Football Arena — مشروع كرة قدم ثلاثي الأبعاد

نسخة تأسيسية قابلة للعب على Godot 4.7.2. المشروع مصمم ليبقى قليل الملفات حتى يسهل تعديله من GitHub على الهاتف.

## الموجود في هذه النسخة

- ملعب ثلاثي الأبعاد بخطوط ومرميين ومدرجات وإضاءة ليلية.
- فريقان، 11 لاعباً لكل فريق.
- نماذج لاعبين ثلاثية الأبعاد أصلية مولدة برمجياً من أجزاء منفصلة: رأس، شعر، جذع، قميص، شورت، ذراعان، ساقان وحذاءان. هذه نماذج ألعاب مبسطة وليست مسحاً ضوئياً أو نماذج بشرية فائقة الواقعية.
- حركة أساسية للاعبين ورسوم جري بسيطة، وذكاء اصطناعي أولي للخصم وزملاء الفريق.
- كرة فيزيائية، تسديد، تمرير، تبديل اللاعب، انطلاق، احتساب الأهداف والنتيجة.
- كاميرا Broadcast عالية تتبع اللعب.
- واجهة عربية للمباراة والقائمة والفريق والبكجات وسوق اللاعبين.
- نقاط وعملات، فتح بكجات عادية ونادرة، شراء لاعبين من السوق.
- حفظ محلي للعملات والتشكيلة عبر `user://profile.cfg`.
- تحكم لوحة مفاتيح للاختبار وتحكم لمس للأندرويد.
- GitHub Actions لفحص تشغيل المشهد وبناء APK وإرفاقه كـ Artifact.

## التحكم

- الكمبيوتر: WASD أو الأسهم للحركة، Space للتسديد، E للتمرير، Tab لتبديل اللاعب، Shift للانطلاق.
- الهاتف: عصا افتراضية يسار الشاشة وأزرار التسديد والتمرير والتبديل والانطلاق على اليمين.

## التشغيل

1. افتح المشروع في Godot 4.7.2 أو أحدث إصدار مستقر متوافق.
2. شغّل `main.tscn`.
3. اختر «مباراة سريعة» أو افتح الفريق والبكجات والسوق.

## البناء عبر GitHub

ارفع محتويات هذا المجلد إلى مستودع GitHub. سيعمل ملف `.github/workflows/android.yml` عند كل تحديث على فرعي `main` أو `master` أو يدوياً من تبويب Actions. بعد نجاحه ستجد APK ضمن Artifacts في تشغيل الـ workflow.

## حدود هذه النسخة بوضوح

هذه نسخة لعب أولية موسعة وليست لعبة بمستوى PES/eFootball. لا تحتوي بعد على لعب إنترنت فعلي أو مزامنة حسابات أو تعليق صوتي أو تحكيم كامل أو تسلل أو بطولات أونلاين. لا توجد أسماء أو صور أو شعارات أندية ولا لاعبين حقيقيين؛ جميع الأسماء والفرق تجريبية. يلزم خادم ومزامنة موثوقة لاشتراك الأصدقاء عبر الإنترنت، وهو غير مضمن في هذه النسخة.

لا تعتمد النسخة الحالية على نماذج أو صور من طرف ثالث؛ أجسام اللاعبين والملعب والواجهة تُنشأ من مجسمات Godot القياسية وبرمجياً داخل `main.gd`. لذلك لا توجد ملفات أصول مجهولة الترخيص. Godot Engine نفسه مرخص بـ MIT؛ راجع https://godotengine.org/license/.
